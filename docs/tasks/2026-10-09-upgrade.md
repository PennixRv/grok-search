# 2026-10-09 Grok upgrade

## Scope

This owner record implements the approved Pennix upgrade plan for the private
`grok-search` component. It removes the Firecrawl runtime/configuration surface,
adapts the upstream serialized-output byte budget, and keeps the existing
Tavily/Direct retrieval contract. The package remains private and is not
published to npm.

The lifecycle-managed Pennix collection is the installation owner. This
repository retains the `bin/grok-search` dispatcher and does not add a second
installer or global npm installation path.

## Acceptance

- `npm test` and JavaScript syntax checks pass.
- `firecrawl` is rejected as an old explicit provider value and is absent from
  active runtime/configuration/documentation surfaces.
- Serialized JSON stdout is bounded at 45 KiB; complete oversized output is
  retained in the private output directory when available.
- `package.json` and `package-lock.json` are version `0.3.0`.
- Main, annotated `v0.3.0`, source archive, checksum, and GitHub Release are
  created without including this owner task or runtime dependencies.
